# JuaKatiba

RAG platform for Kenya Gazette and Kenyan electoral law access.

## Mission
Democratize access to Kenyan civic and legal information with a hallucination-resistant architecture.

## Tiers
- **Public Tier:** Accessible, plain-language civic assistant.
- **Enterprise Tier:** Air-gapped legal assistant with strict auditability.
